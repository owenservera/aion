# Owners
- **ZCode**: owns execution: tasks, code, review, commits. BFF does execution/evidence coordination under ZCode's path.
- **AION PM**: plans, prioritises, tracks this ledger, accepts work. Does not execute.
- **Owen**: privileged Windows actions, credentials, consequential decisions. Reachable via phone/PWA only.
- OpenCode is subordinate to ZCode. CCR routes inference only.
