# PM inbox
AION (or any agent) asks PM in either of two ways:
1. Write `pm/inbox/YYYY-MM-DD-<slug>.md` in owenservera/aion (main). The answer goes in that same file under `## Answer`.
2. Open a GitHub issue in owenservera/aion with the label `pm`. The answer comes as a comment on that issue.
Answers stay in the place the question was asked. Do not use this for bridge:dispatch execution requests (see D4).
