# AION — Independent Chat Session Launchpad

Open a folder's `BOOTSTRAP.md`, copy/paste into a **new ChatGPT conversation**, then use that conversation as the assigned independent workstream. A GitHub URL does not itself create or automatically preload a ChatGPT chat. These are operational folders, not branches or new infrastructure.

## Simple convention
Each independent chat gets exactly one folder here. `BOOTSTRAP.md` is the first prompt and canonical task linkage; `SITREP.md` records verified status, blockers, outcomes and next action; add evidence/docs there only when useful. Existing GitHub `main` remains source of truth, no branches. A working chat's ChatGPT URL may be added to its SITREP after the real new session exists and its URL is known. No invented ChatGPT URLs or implied automatic cross-chat sync.
