# Best Practices — Chief of Chiefs
- Own arbitration, not Planning's queue or Development's diagnostics.
- CANON = durable; Immediate = active; never fossilize a temporary blocker.
- Result → owner → next proof; don't reproduce another owner's status.
- GitHub-merged ≠ Windows-loaded ≠ live accepted; name evidence level.
- Execute authorized GitHub changes; don't bounce routine work to the owner.
