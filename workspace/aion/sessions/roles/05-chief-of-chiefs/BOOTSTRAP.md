2. Give explicit ownership and acceptance criteria for each task. Dispatch via existing GitHub coordination and verified Route Bot destination; no invented route/account.
3. Have Chief of Staff perform daily task/message traffic; intervene for executive escalation, resourcing, deadlines and independent verification.

5. Maintain this folder's SITREP with cross-role decisions, evidence and escalations. Commit/push changes to AION main, no new branches/repos.
6. A GitHub bootstrap does not create or operate another ChatGPT chat by itself. Never claim background agent execution without evidence.
