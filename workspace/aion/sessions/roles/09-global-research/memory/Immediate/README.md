- **Owner priority:** full, untruncated, incremental capture of **browser-received raw ChatGPT.com response data** to the local Windows machine (L1 bytes/fragments + L2 protocol envelopes), **not just the rendered DOM**. [Dedicated lab](../../labs/website-to-local-streaming/README.md), [ranked methods](../../labs/website-to-local-streaming/RAW-STREAMING-OPTIONS.md), [canonical issue #30 comment](https://github.com/owenservera/aion/issues/30#issuecomment-6316115992).
- **Highest-value feasibility test:** isolated, temporary read-only CDP Network observation: experimental `Network.streamResourceContent`/`dataReceived`, WebSocket frame and EventSource message events, while comparing the existing AION DOM receive. Official protocol permits these event types but **does not establish that an actual chatgpt.com model response uses them or can be captured completely on this Windows build**. Test exact signed-in tab, short/long response, disconnect and byte/timing continuity. Do not broaden the live extension's debugger privileges merely to scout.
- **Definitions:** “unbounded” means **no chosen truncation or summarization of observed response content**, with append-only local archival and bounded memory/backpressure. It does **not** mean infinite resources, guaranteed browser/network losslessness or access to hidden server-only data.
