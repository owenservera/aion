# notebooklm


**Trigger:** multi-document synthesis, podcast/video source comparison or research-heavy source notebook. NotebookLM is an optional research instrument, **not** the intake queue, database or authoritative documentation library.

**Tier detection:** (0) No direct NotebookLM connector currently discovered in ChatGPT (checked 2026-10-19); consumer NotebookLM at notebooklm.google.com requires an authorized user-driven workflow unless verified capability changes. (1) Use connected Drive to find authorized source Docs/Slides and provide a source list with exact permissions and links; do not assume Drive OAuth grants NotebookLM access. (2) Google documents a **Gemini Notebook Enterprise** preview API to create/manage notebooks and add Drive Docs/Slides, text, web sources and YouTube URLs, but it requires an enterprise setup, licensing, Google Cloud IAM/auth and supported endpoints. Check current official docs and actual account capability before calling. Do not use undocumented consumer endpoints or browser credential automation.

**Workflow:** rank documents, avoid redundant/large sources, resolve sharing/rights, set a notebook purpose and source manifest (URL, version/date, expected question), capture citation-grounded findings and unresolved contradictions; export derived notes only into SOFTWARE_HQ/owning repo through approved path. Mark `PREPARED_FOR_NOTEBOOKLM`, `INGESTED_VERIFIED`, `OUTPUT_VERIFIED` separately. If tier 0, research with other tools without blocking intake, and give owner one clear option to enable a supported connector/account in future.
