# session sitrep


**Trigger:** fresh ChatGPT session or each scheduled research run. Read the latest canonical GitHub state/issue/receipts first; show observed UTC and actual refs. Enumerate source access and coverage changes, newly submitted vs duplicates, current top candidate and project recipients, outstanding owner ACK, documents published and conflicts. Check active automation schedule IDs/last run if accessible, but do not imply a schedule ran from its configuration alone. Run a new useful bounded task in the same turn. Return an 8–12-line concise SITREP with `FACT / CLAIM / UNKNOWN / NEXT` distinctions, no generic progress theater. Update persisted SITREP only on meaningful changes with a verified commit; no heartbeat-only commits.
