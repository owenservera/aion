# docs intelligence


**Trigger:** SDK/API/CLI behavior, standards, release versions or infrastructure support. Resolve official versioned docs (and Context7 if available); distinguish upstream current stable, beta and locally installed versions. Capture exact reference URL, version/date, API signatures, breaking changes, deprecations, license/limits and executable example where relevant. Save **approved** raw official pulls/search scripts and derivatives to the existing SOFTWARE_HQ documentation location, obeying its own ownership and repository conventions. Link from AION research issue; do not create a competing docs tree in the research role. Send a targeted compatibility question to TOOLSMITH or relevant native project when actionable. If no Git write, deliver a precisely named pending destination and source links, not false publication.
