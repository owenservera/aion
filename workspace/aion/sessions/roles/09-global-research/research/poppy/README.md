# Poppy — Personal Agent Protocol | AION RESEARCH

**Owner:** AION RESEARCH / Role 09  
**Created:** 2026-10-25  
**Scope:** research evidence, protocol comparison and low-build single-user applicability — **not** an agent executor, implementation, approval or production integration.

Poppy is the proposed open standard for a personal agent to discover a participating company, maintain a cross-channel Session, and request user-authorized access across an API, browser or company agent.
