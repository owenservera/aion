# Webapp-native shape evidence skill (role 14)

**Scope:** Evidence review, model construction, fixture/test specification and owner-directed source integration advice. A checked-in SKILL.md is NOT an installed or invoked local tool and does not authorize Windows/Chrome access.

## When to use
A request concerns ChatGPT/Claude rendered responses, stream carriers, artifacts, context, agentic tasks, citations, output component types, browser actions, provider-native identities, DOM-to-stream join or agent harness semantic projection.

## Procedure
1. Establish the target `provider`, `surface` (chat, research, Work/Cowork, artifact, project), date, repo SHA and evidence class. Prioritize governing Capture Studio architecture and original source.
2. Inspect existing `docs/AI-CHAT-SHAPES.md` and `src/{profiles/stream-map,decode/protobuf,replay/stream-components,replay/stream-role,intel/join}.mjs` first. Prefer already retained local raw references; never request private transcripts in Git.
3. Separate `OFFICIAL_PRODUCT_DOC` / `API_REFERENCE_ONLY` / `SOURCE_INSPECTED` / `SAVED_REAL_CAPTURE` / `SYNTHETIC_TEST` / `SANDBOX_REAL_BROWSER` / `WINDOWS_LIVE_ACCEPTED` / `UNKNOWN` at each claim.
4. Extract only *observed* native identities, component ordering/types, revisions, visible controls, stream source and coverage. Preserve unmatched blocks and untrusted page content as data. A public API type is not proof the website emits it.
5. Design loss-aware projection. Explain which native structures are first-class: citation, rich code, visual answer, source, thinking SUMMARY, provider tool activity, artifact/version, Work/Cowork task, branch/generation and failed/incomplete states.
6. Write high-value discriminating tests including identical old reply, wrong-thread, virtualized history, remounted DOM, unauthenticated site, lost effect ack and dissimilar DOM/network carrier.
7. Hand a targeted recommendation to existing Core/UI/QA/Research/Z-FORGE owners, with exact source seam and acceptance outcome; no second browser actuation, no replay of private endpoints.
8. Record source URLs/date, version/commit, evidence class, counterexamples, failure boundary, and next observation. Change specialist docs only on meaningful findings.

## Deliverable template
`Question; observed site/surface/version; source citations/refs; native shape; proposed projection; missing/lost fields; currently available actions; negative cases; evidence class; reviewer/executor handoff.`

## Red lines
No Playwright, Puppeteer or Orca; no paid model APIs; no credentials in git; no unauthorized browser effects; no claiming access to hidden reasoning or full history; no second AION writer; no claim a staged Git patch was installed or a GitHub issue woke an agent.
