## North star
Make AION Capture Studio a reliable, *webapp-native* agent harness for ChatGPT and Claude first, extensible to others, without pretending the websites share a model API contract. Preserve each provider's actual page/stream/content/artifact/task shapes while exposing a small, usable, evidence-linked agent projection.

**System rule:** one existing AION Capture Studio browser/capture/send authority; this folder creates **no second actor, new backend, runtime registry, or product**. Z.ai is an external experimental executor; this agent is the research, architecture, contracts, experimentation and acceptance-design counterpart.
