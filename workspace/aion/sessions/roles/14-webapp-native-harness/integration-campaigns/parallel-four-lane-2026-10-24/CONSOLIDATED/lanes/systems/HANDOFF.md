## Exact proposed wire contracts (all advisory; caller validates server provenance)

1. `qualifyHoldout({ train: SessionManifest[], heldout: SessionManifest[], expectedScope })`. Scope `{siteId, origin, account, surface}`. Manifest `{id,lineage,scope,sourceDigest,coverage:'complete',coreAccepted:true,sourceQualified:true}`. `lineage` must be minted from immutable capture provenance independent of filenames or client IDs; **not** merely a client-provided string. Return `qualify-shadow-only` or `abstain(reason)`. For existing Round 9 gate, call it **first** for backward compatibility, then apply stronger independent manifest qualification before `shadowEvaluate()` and `promote()`.
2. `auditEffectTrace({binding,events})` receives a **durably pre-effect** binding from the actual intent owner and ordered matching journal evidence, never raw text. This checker may find invalid traces or uncertainty, but the current journal's definitive read/reconcile API remains owner. A returned `delivery-observed-not-outcome-accepted` proves neither reply completion nor G1–G7. Do not turn `pre-effect-blocked` into retry permission.
3. `assessDrift({scope,incumbent,proposal,observations})` requires signed/source-qualified observation metadata and monotonically resolved capture-window provenance from the producer. On success, invoke *existing* independent shadow/read-only version process; require a last-known-good profile pointer. The module does not change `CURRENT`.
4. `createBoundedProjection({maxStreams,maxChars}).offer({scopeKey,streamId,revision,text})`: UI-only latest revisions, with `UI_PROJECTION_OVERFLOW` and `truncated` surfaced. Keep authoritative raw/derived stream and source offsets outside this cache; clear when the exact binding/epoch changes. Native event blocks, citation positions and artifacts must not be flattened to this text preview. Use the same Studio event source, not another WebSocket/producer.
5. `qualifyProvenance({acceptance,validatedByCore,source,expectedScope,refs})` accepts the actual acceptance file shape: `{schema,verdict,binding:{rawDigest,domDigest,seqRange},gates}`. `source` includes immutable `sessionId,rawDigest,coverage,gaps,scope`; refs contain `sessionId,rawDigest,origin,account,seq`. **Only an internal Core verifier may supply `validatedByCore=true`.** It is not a persisted acceptance-file field. Recheck raw sha and DOM binding in the existing acceptance writer/reader, not this pure predicate.

All output statuses are **diagnostic**. No `sendPermission:true`, autonomous profile promotion, raw mutation, browser effect, `capture_accepted` emission, automatic source-to-knowledge promotion or file lock release exists in these modules.
