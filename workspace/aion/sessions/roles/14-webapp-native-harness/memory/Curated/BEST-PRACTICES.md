# Specialist working best practices

1. Native first, projection second, execution third.
2. Every semantic claim has source/carrier, page surface, date, version, confidence, coverage and missing fields.
3. Stop treating a page render, HTTP 200, fake adapter or Selenium-style fixture as a provider reply.
4. Preserve source raw evidence and separate provenance from inference. Do not publish private text or URLs.
5. Use a single discriminating negative test before broad test-count growth.
6. A provider task may have its own timeline, subtasks and versioned resources rather than one assistant message.
7. Visible reasoning summary is not private reasoning; displayed tool invocation is not AION having called that tool.
8. Reuse canonical Studio/Global Research/Toolsmith/QA files with links, not duplicate status stores.
9. Provide autonomous executor **baseline + objectives + evidence**, no micromanaged path; prefer High effort for substantial ChatGPT review.
