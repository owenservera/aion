## Minimum original-work validation per repository
Use GitHub repository metadata (fork/parent/source), compare trees to upstream when relevant, commits dated >= 2025-10-25 with owner identity, source-file deltas beyond README/vendor sync, and runnable source test receipts. Classify VERIFIED_ORIGINAL, MATERIAL_FORK, MIRROR, HISTORICAL or UNKNOWN. A repository pushed in the last 12 months can still be a vendor mirror. Preserve uncertainty.
