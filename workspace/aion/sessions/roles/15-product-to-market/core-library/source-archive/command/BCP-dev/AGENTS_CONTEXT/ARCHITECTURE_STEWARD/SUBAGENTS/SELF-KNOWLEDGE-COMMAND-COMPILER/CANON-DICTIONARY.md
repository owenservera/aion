# CFA-03 CANON Dictionary — Foundation

> Status: FOUNDATION / INITIAL ENTRIES
> Scope: Semantic Continuity Steward
> This is a bounded terminology instrument, not Ω law and not the universal VIVIM ontology.

## Initial semantic distinctions

| Term | Working meaning | Status | Boundary / contrast |
|---|---|---|---|
| Self-knowledge | A derived description of VIVIM/system state assembled from permitted evidence. | CURRENT / DERIVED | Not authority; not the canonical world itself. |
| WorldModel | Runtime grounding model used by current NCLL/self-knowledge machinery for a bounded world projection. | CURRENT / DERIVED | Not the future universal data model. |
| Grounding | Resolving references and meaning against available world/system knowledge and evidence. | CURRENT / DERIVED | Does not authorize execution. |
| Interpretation | Result of deterministically resolving input against the available command/world model, including reading and diagnostic state. | CURRENT | Distinct from execution. |
| Canonical semantics | Stable semantic representation that downstream Intent/Work meaning refers to. | DERIVED | Distinct from surface text or visual representation. |
| Intent | Persisted representation of the requested goal/command at the Intent contract boundary. | CURRENT | Distinct from Plan, Work and execution. |
| Plan | Execution-oriented decomposition/plan referenced by Intent where applicable. | CURRENT / SCOPED | Not equivalent to user intent. |
| Work | Durable outcome entrusted to the system for execution and lifecycle management. | CURRENT | Not a parser result. |
| Evidence | Material supporting an observation, derivation, production or claim. | CURRENT | Evidence informs; it does not grant permission. |
| Authority | Rule, scope, consent or delegation boundary determining what may occur. | CURRENT | Not derived from evidence or confidence. |
| Representation | Human- or agent-facing projection of canonical meaning. | DERIVED | Never authoritative merely because it is visible. |
| Visual projection | Visual, Unicode or SVG representation of canonical interpretation/intent. | PROPOSED / INCREMENTAL | Must share the semantic source used by V1. |
| Visual write-back | Deterministic conversion of a permitted semantic visual edit back into canonical meaning. | PROPOSED | Must not bypass authority or create parallel semantics. |
| Confidence | Ranking signal used during interpretation/candidate ordering. | CURRENT | Confidence is not proof. |
| Proof / verification | Evidence-backed establishment of a property under a defined test, probe or authority. | CURRENT | Never inferred from confidence alone. |
| Freshness | Derived statement that a required evidence basis still matches the current basis of a derived view. | DERIVED | Time alone is not proof of currentness. |
| CANON | Bounded terminology and crosswalk instrument maintained by CFA-03. | PROVISIONAL NAME | May be renamed after terminology archaeology. |

## Explicit non-equivalences

Self-knowledge ≠ authority

Grounding ≠ authorization

Confidence ≠ proof

Interpretation ≠ execution

Intent ≠ Work

Representation ≠ canonical identity

Visual projection ≠ execution authority

Historical name ≠ current canonical meaning

## Entry discipline

Before promoting a term to stable vocabulary, capture:

- definition;
- semantic owner;
- authority source;
- evidence;
- aliases;
- historical names;
- contrasts/non-equivalences;
- lifecycle status;
- decision rationale.

Do not perform repository-wide mechanical renames merely to make this file consistent.
