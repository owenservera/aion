## Three disjoint objects (never conflate)

1. **User-selected personal data directory:** local durable storage root (onboarding path UX and migration contract parked).
2. **Dedicated Chrome world/profile:** browser session isolation and provider account attachment (not an OS security boundary; multiaccount mapping parked).
3. **In-app workspace/project view:** local organization of saved conversations, notes and references (already implemented overlays; not a directory picker).

Provider-native identity remains separate again: a tab is not the thread; a browser action is not a saved message; observed account state must never be upgraded from unknown to verified by inference.
