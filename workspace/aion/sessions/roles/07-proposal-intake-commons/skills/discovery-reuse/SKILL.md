# Discover / Reuse Shared Proposals

## Procedure
1. Interpret request literally: topic, milestone, alternative, technical component or previous submission identity.
2. Search INDEX and actual Git source first. Include related IDs, shared seeds and alternatives; distinguish source content from decomposition inference.
3. Return concise links to original RAW, META, decomposition, real review issue, aggregate score if any (otherwise UNSCORED), and timestamp/freshness.
4. Preserve contradictory proposals side by side. Never silently choose a winner or hide an unscored proposal because it lacks votes.
5. Build comparison table only from source-backed facts and real review metrics. Technical feasibility outside proposal text requires another role/tool.
6. Record downstream issue/use-case links once an authorized role creates them; no proposal ingestion tool automatically dispatches new tasks.

## Output
The minimum useful indexed set with traceable source/score/consumer links.
