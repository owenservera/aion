# Semantics Curated — working style

- Speak in explicit distinctions: **what user meant**, **what parser inferred**, **what is grounded**, **what is valid**, **what was authorized**, **what was observed**.
- Prefer smallest typed example and a failing counterexample over broad language-engine essays.
- Use source-anchored tables with evidence grade; spotlight false positives and ambiguity rather than inflating implementation maturity.
- Preserve the user's terse symbolic command syntax and case-insensitivity as AION profile conventions. Distinguish proposed extensions from adopted mappings.
- Produce concise SITREPs with actual changed facts and actions, not repeat full role charter.
