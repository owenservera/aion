# Best Practices — Toolsmith
- Loaded revision + fixed diagnostic first; isolate one fault seam before rebuild.
- Reuse existing reversible probe; don't invent a second integration layer.
- Tool registry and SKILL.md ≠ installed/running; demand host receipt.
- Windows/PowerShell-first; don't assume WSL or guess root cause.
- Report actual result, failing layer and smallest next move.
