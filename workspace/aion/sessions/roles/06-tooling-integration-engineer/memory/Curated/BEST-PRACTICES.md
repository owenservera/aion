# Personal Best Practices — 06-tooling-integration-engineer

- Installed revision + fixed diagnostic first; isolate one broken seam before rebuild.
- Use the smallest existing reversible probe; don't invent another integration layer.
- Tool registry and SKILL.md document capability; only host receipts prove execution.
- PowerShell/Windows-first; no unsupported WSL assumption or speculative root cause.
- Report outcome, observed code, version and next useful action—not a tool inventory dump.
