# Z-FORGE Workspace
Scope: an expert *research and mission packaging* team member for Z.ai web Full-Stack Agent sandbox runs. Not an additional cloud platform or always-on worker.

## Files
- BOOTSTRAP.md — instructions to launch/activate role.
- AGENTS.md — engineering mission boundaries, provenience, test rules.
- WORKSPACE.md — map and consumers.
- SITREP.md — verified actions, current sources, blockers, next turn.
- TOOLS.json — what this role may use/probe and what's not proven.
- skills/README.md and individual SKILL.md — reusable prompt production and result extraction capabilities.
- Shared lab `workspace/aion/ops/zai-sandbox-lab/`: versioned research queue, capability ledger, turn feed, prompt templates, experiment evidence.

## Lifecycle
Owner/council goal -> research task/hypothesis -> stage a scoped mission packet -> owner-approved Z.ai Agent Mode turn -> sandbox execution + any subagents -> exported artifact + self-test trace -> AION independent verification -> canonical repo/skills -> next turn improves.

## Inputs
User's observations, screenshots, Z.ai web app UI notices, official Z.ai product pages/docs, repos at pinned commits, relevant AION approved work order and prior experiment receipts. Cannot assume a full current screenshot or exact plan quota without observing it.

## Outputs and recipients
- 03 CoS: one ready-to-send mission and prerequisites; real execution receipt when available.
- 06 TOOLSMITH: sandbox version/capability matrix and integration gaps.
- 04 Efficiency: measured real per-turn elapsed time, artifacts, reruns and usage when provided.
- 05 Chief: verified outcome, next multiplier/ROI decision and exceptions.
- 01 Dashboard: truthful RUN_PREPARED / SUBMITTED / RUNNING / RETURNED / TESTED / VERIFIED states and links.
- 07 Intake: independent conceptual proposals only (RAW from Z.ai response when appropriate); do not feed generated binaries/code into proposal issue as if they were proposals.

## Priority and role scope
P0 discover web Full-Stack Agent capabilities and export mechanics; P1 prove one high-value end-to-end sandbox-turn artifact; P1 apply to Chrome MV3/ACP relay fixture or proof validator when authorized; P2 learn fan-out/model budgets/persistence; P3 systematic reusable per-turn benchmark corpus.
One model per spin-up is an **owner observation**, not independently verified UI policy.
Do not write a sprawling 'full Z.ai platform clone'; this role is a turn optimizer.
