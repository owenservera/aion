# Intra-Turn Team Fanout
**Trigger:** A complex turn can benefit from parallel independent subwork and web Agent Mode actually exposes such tools.

1. Validate subagent availability and delegation interface in this exact Z.ai web Full-Stack run; sibling product features do not count.
2. Break task into independent results: recon/interface mapping, implementation, negative-test verification, artifact bundling. No two agents modify the same file unless one is reviewing a final snapshot.
3. Assign precise owners, input paths, output files and acceptance. A parent merges and resolves conflicts.
4. Independent QA subagent should attempt to falsify the build, not merely repeat the implementer's claims. Record tool traces if the service exposes them.
5. If UI doesn't permit explicit spawning, don't pretend. Main agent can execute work serially or use service-provided orchestration without unverifiable claims.
6. Capture measured parallel efficiency vs overhead and report to Role 04.
**Pass:** actual separated output and merged validated artifact. Agent labels in a prompt alone are not proof.
