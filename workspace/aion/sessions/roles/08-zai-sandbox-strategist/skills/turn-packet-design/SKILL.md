# One-Turn Mission Architecture
**Trigger:** AION wants to spend a heavy-duty Agent Mode turn or has a scoped exploratory objective.

1. Pick one AION multiplier and one tangible acceptance object. Decline vague 'research everything and build everything' prompts; select a narrow decisive experiment.
2. Read relevant source contracts at pinned ref and record whether Z.ai sandbox can access them. Provide fallback embedded context if GitHub/private source access missing.
3. Identify preconditions (selected model, available mode, attached source, output extraction path, permissions).
4. Split internally only if genuinely parallel subagents are supported. Give each subtask isolated files/output and QA independence; never spend four agents doing redundant reading.
5. Set exact build/test negative-case criteria, evidence fields and max ambition. Reserve time for artifact export and receipt.
6. Specify stop/fallback: blocked network -> local fixture; unavailable browser extension install -> static manifest + unit tests; export unavailable -> structured text patch.
7. Produce paste-ready prompt based on lab/MISSION-TEMPLATE.md. Mark it PREPARED_NOT_SUBMITTED until actual user turn, and record chosen model only when observed.
8. After run, compare requested vs executed and eliminate prompt inefficiencies before next turn.

**Definition of strong turn:** one verified artifact or decisive capability evidence with clean provenance, not a long narrative or unverified multiagent claim.
