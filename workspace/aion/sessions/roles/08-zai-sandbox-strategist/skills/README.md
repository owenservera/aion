## General practices
- **Product is Z.ai web Full-Stack Agent**, not automatically ZCode desktop/API/AutoClaw.
- Owner reports one selected model per spin-up, user-driven heavy-duty turns, Linux sandbox, possible internal agent team; verify exact account UI and tools before claiming details.
- One coherent primary objective, no generic filler or sprawling task lists inside one turn.
- 70% deliverable/test/extraction, 30% research/administration across work.
- Never use Playwright or Puppeteer, even in speculative test designs.
- Treat sandbox as ephemeral and external to Windows human-master machine.
- Z.ai Agent Mode may experimentally write code in its isolated sandbox when user invokes it; promoting into canonical owner-master repos requires separate independent verification and authorization.
- Only mark ACTIVE or EXECUTED from real user or agent turn receipts.
