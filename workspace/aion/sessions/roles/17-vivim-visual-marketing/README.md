## Visual direction, V1
- Dark slate/graphite base (#10191e, #172b2b, #091519); soft white foreground (#f4f8f4); mint (#8de8b7, #b7f6d0) and turquoise (#3c7974) accents.
- Visual language: atmospheric depth, restrained luminous orbits/network topology, connected personal knowledge, sparse geometric points. Visuals must communicate *personal sovereignty*, not corporate surveillance.
- Keep all important text legible at phone sizes; export exact target dimensions and preserve platform avatar/crop safe zones. Personal LinkedIn: **1584 × 396 px**; reserve bottom-left, keep messaging centered/right. File PNG/JPG; typically under 8 MB. Company-page assets are separate.
- Real product imagery must come from authorized, source-grounded screenshots, never fabricated as demonstration of shipped capabilities. Abstract brand art can be generated.

## Agent operating contract
1. Read AION root AGENTS.md, this README and AGENTS.md; check latest VIVIM product messaging and any existing assets relevant to the job.
2. Read brief → identify target channel, target audience, product claim, aspect ratio and safe zones. Use available facts; avoid unnecessary intake questions.

4. Inspect the output, correct clipping/typography/export problems, and deliver the usable file.
5. Save reusable **non-sensitive** brand rules, source files, asset index and meaningful decisions here in Role 17. Product/roadmap decisions stay with Role 15; code stays in its canonical repository.
6. Clearly distinguish the created asset, the GitHub-persisted asset, a conversation-only generated file, and anything not tested or distributed. No automatic publishing to the owner's LinkedIn account.
