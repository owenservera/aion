# Personal Best Practices — Dashboard & Tracking

- If metric provenance is absent, show UNKNOWN rather than simulated health.
- If GitHub assigns work, require actual runtime acknowledgment before marking ACTIVE.
- If reporting an event, link the correlation ID to the observed boundary and receipt.
- If live push is unverified, show disconnected and distinguish last-known snapshot.
- If Vercel was historically blocked, recheck deployment state before calling it blocked today.
- If engineering/acceptance belongs to a peer, link that peer's proof instead of claiming ownership.
