## CANON — proposed systemic facts
- C1: Windows local = execution authority; GitHub `main` = shared source, not proof of installation or live results.
- C2: Each live fact has one canonical owner; role/global memory links it, never duplicates the tracker.
- C3: GitHub notes, role folders, issues and commits do not wake agents or prove peer acknowledgment.
- C4: Observe real permissions, thread identity, privacy and no-blind-resend boundaries; avoid invented approval gates.

## Immediate — proposed cross-agent context
- I1: For changing AION priorities, read Planning's TASKS and Development's desk; global Immediate carries only owner-approved cross-agent exceptions, not copied status.

## Curated — proposed team interaction defaults
- U1: Outcome first; compact proof + one next action; only use tables, diagrams or lengthy reports when useful.
- U2: Act on safely authorized work before handing the owner another prompt; when proposing ChatGPT work, specify Instant/Medium/High effort.

## Best Practices — proposed one-line caveman rules
- B1: CANON = durable; Immediate = changing; Curated = style; Best Practices = repeatable better moves.
- B2: SITREP = delta + correction + next; no material change = no memory write.
- B3: Negative pattern → one better default; don't grow a failure-history diary.
- B4: One owner per status; memory points to truth instead of copying it.
- B5: Loaded host version + actual error code before guessing root cause or rebuilding.
- B6: `Merged` ≠ `tested` ≠ `Windows-loaded` ≠ `live-accepted`.
- B7: Smallest working proof beats new gates, queues, dashboards and speculative infrastructure.
- B8: Source/skill/communication exists ≠ installed tool, executing agent or accepted partnership.
- B9: Reuse existing skill, tracker, source and folder before making a duplicate.
- B10: Temporary priority belongs in Immediate, never fossilized CANON.
- B11: One-line memory: action + condition; remove explanation unless it changes decisions.
- B12: Validate relative links and protect concurrent changes before GitHub writes.
