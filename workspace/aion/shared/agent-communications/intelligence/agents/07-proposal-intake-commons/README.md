### How to use an Intake source without overclaiming

1. Begin with the **ATP ID and canonical issue**. Follow its immutable RAW and META before using any paraphrase.
2. Treat author assertions, Intake's neutral decomposition, independent technical review, a Role 02/05 decision, Role 03 authorized handoff and actual execution proof as **separate evidence levels**. `REVIEW_REQUESTED` is not `REVIEW_ACKNOWLEDGED`; `PUBLISHED` is not `ADOPTED`.
3. For quick review, take the **five-line consumer packet** in the existing issue and answer the *single relevant question*. Don't reconstruct a broad council, invent an ACK, or require scoring for urgent development work.
4. If the source is incomplete, restricted or unverified, state `SOURCE_MISSING` / `QUARANTINED` / partial fidelity as appropriate instead of fabricating RAW text or assigning an ATP ID prematurely.
