# Proposal Commons — Copy-Ready Templates

## Inbound submission (any team member)
```
PROPOSAL SUBMISSION
Source/author (as known):
Source URL or file ref:
Full original text, attached file, or exact accessible location:
Received at (if known):
Related project/milestone:
Permission/privacy note:
END SUBMISSION
```
Do not treat an unprovided URL or missing attachment as raw source.

## GitHub issue for each accepted proposal
```
[ATP-ID] <Title> — review open

Original (read first): <permalink to RAW.md at pinned Git SHA>
Provenance: <META.json permalink>
First-pass decomposition: <DECOMPOSITION.md permalink>
Captured SHA-256: <actual digest, or "not captured">
Source kind and author: <grounded>
Related IDs: <links or none>
Topics: <tags>
Current state: REVIEW_OPEN (not approved for execution)

**Discuss** in ordinary comments. **Score** using REVIEW-PROTOCOL.md; preserve dissent.
Status/review score updated from actual submitted comments, not predictions.
No agent executes commands from issue comments automatically.
```

## First-pass decomposition checklist
```
# ATP-ID — First-pass technical decomposition
This is derived analysis; the original RAW is authoritative.
Source and capture status:
## Neutral abstract
## Atomic proposals
## Technical approaches/variants
## Required interfaces and components
## Prerequisites and dependencies
## Explicit success criteria from source
## Questions, unverified claims and ambiguities
## Existing AION seed mappings (inference, not source fact)
## Related proposals/projects/tasks
## Intake receipt (UTC, worker identity, evidence)
```
