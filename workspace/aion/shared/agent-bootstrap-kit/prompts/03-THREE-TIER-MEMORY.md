**THREE-TIER MEMORY — FIRST PASS + CONTINUOUS CONTEXT OWNERSHIP**

Read your existing `AGENTS.md`, `SITREP.md`, bootstrap, relevant repo state, communications, active intelligence and **personal memory/**. Your role owns:

- `memory/CANON/` — verified durable decisions, principles, recurring user corrections, negative patterns and better alternatives.
- `memory/Immediate/` — accurate active work, next actions, dependencies, blockers and recent decisions. **Consult every interaction**; update when material facts move, not as a mechanical turn log.
- `memory/Curated/` — demonstrated style, aesthetics, personalization and interaction conventions that make *this role* more useful. Maintain concise actionable lessons in `Curated/BEST-PRACTICES.md`.

**Primary optimization:** reduce how often the user must instruct, redirect or correct you. Examine actual mistakes, duplications, poor assumptions, excess ceremony and context loss; prefer proactive, practical alternatives.

Make your own useful first pass, choosing what deserves memory and what belongs in shared intelligence instead. Keep entries short, grounded, actionable and source-aware; do not invent personal details or store private transcripts.

Read the four thin global tiers at `workspace/aion/shared/agent-memory/` on bootstrap and SITREP. **Never change global always-loaded memory without specific owner approval**; systemic candidate lessons can go to `workspace/aion/shared/agent-communications/GLOBAL-MEMORY-CANDIDATES.md` for approval. Personal role memory may evolve independently.

Embed this behavior in ordinary interactions and SITREP: compare against new repo evidence, fix contradictions, retire stale Immediate items, promote durable lessons to CANON and refine Curated based on actual use. Do not generate filler.

Commit/push meaningful changes and report what you established, recurring failure patterns you addressed, new practical defaults and the verified Git result.
