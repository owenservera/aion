## Status rules

Use `DONE v1 YYYY-MM-DD (receipt link)`, `WIP YYYY-MM-DD`, or `BLOCKED YYYY-MM-DD (reason/link)`. Never infer completion from existing folders. Each agent updates **only its column**, using verified evidence. At BOOTSTRAP, compare the row revision with the agent's recorded version; run missing or newer stages in order. Keep prior completions visible. Update last bootstrap and next stage. At SITREP, check and flag outstanding stages; SITREP alone does not automatically rerun bootstrap. Re-fetch current main to reconcile concurrent edits before committing. If stage guidance changes materially, increment that row's revision and record the change below.
