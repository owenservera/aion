# AION V1 — Mobile paste-ready activation packets
These messages bootstrap the **current** chat. They cannot create another native conversation or rename its title.

## Packet 1 — fastest; new chat inside AION Project IF router instructions installed
```

```
This works as a role router only when the *actual* project instructions or initial role bootstrap in that new chat define the command. Shared Project memory may still supply other same-project context. No exact 'workspace-only' guarantee.
