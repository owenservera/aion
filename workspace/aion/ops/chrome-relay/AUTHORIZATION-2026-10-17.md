## G3 as widened by the override — now permitted

- load the unpacked extension in a Chrome profile on this host;
- **fill the real ChatGPT composer** (`#prompt-textarea`) and **submit** via the send button;
- **read the resulting assistant reply** from the page;
- correlate that reply against the outbound correlation ID and deliver it to AION;
- run the **negative case** required by the M1 contract (a mismatched correlation, or a reply not
  generated by ChatGPT, must be **rejected**, not reported as a turn).

Outbound message remains the existing AION-authored one from
`sessions/01-escape-hatch/AION-OUTBOUND-M05-001.md`, loaded via `adapter/lib.js` `loadOutbound()`.
It is benign and contains no account secrets.

## Still NOT permitted — the override did not extend to these

These were never part of what the owner asked for, and enabling them would exceed the stated goal:

- exporting cookies, tokens, session identifiers, or the ChatGPT access token;
- reading bulk conversation history beyond the single correlated turn;
- automated login, session renewal, captcha/Cloudflare handling, rate-limit evasion;
- mass or unattended sending — this is one correlated probe, not a message firehose;
- any undocumented or reverse-engineered ChatGPT API.

## Design rule this override sets aside

`ops/chrome-relay/ARCHITECTURE.md` states: *"Drafting into ChatGPT composer requires a clear user
gesture; automated prompts are NOT a baseline capability."*

**That rule is overridden by owner instruction for this milestone.** It is recorded here rather than
silently deleted, because it remains correct guidance for general use and should be reinstated if the
scope narrows again. Tracked by the M1 acceptance record, not by this file.

## Profile

**Profile 3** is the ChatGPT-capable profile. Loading an extension into a signed-in profile is the
step that puts code into an authenticated session's origin; the grant makes it bounded and
reversible, not consequence-free.

## Rollback

| Step | Undo |
|---|---|
| G1 | `Remove-Item 'HKCU:\Software\Google\Chrome\NativeMessagingHosts\com.aion.relay'` |
| G2 / G3 | `git revert` the manifest commit, or remove the unpacked extension from `chrome://extensions` |
| All | unload the extension + remove the registry key. No repository data is affected. |

The bridge writes no durable state outside the repo; durable evidence belongs in the GitHub ledger, not
in a live session. A ChatGPT conversation that received the probe cannot be un-sent — that is the one
irreversible element, and it is why the outbound message is benign by construction.

## Recording rule

This file records **consent**, not completion. Each grant is only *exercised* when its own receipt is
recorded in `workspace/aion/agents/windows-master/`. Issuing this authorization does not mean any step
has been performed or verified.
