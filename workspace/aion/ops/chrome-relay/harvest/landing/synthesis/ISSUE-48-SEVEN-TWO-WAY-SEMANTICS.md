**Explicit invariants:** (1) advertised capability ≠ fresh action availability ≠ grant ≠ witnessed effect; (2) session idle ≠ reply checked; (3) operation ID ≠ message ID ≠ stream cursor; (4) historical `PROMOTED` ≠ live send-ready; (5) any selector ambiguity blocks Send; (6) unknown possible Send effect is irrecoverable by blind resend; (7) receive authority never inherits Send authority; (8) snippets and page-local cursor cannot assert global history completeness.
