### Actual semantic route, not the advertised universal route

`lex` → recognizers / available frames → slot candidates → `ground` → scored IR + alternatives → token/effect projection is a **reading pipeline** (E01-E05). The D1 route is different: shared lexer/grounder → prompt.send-only verb table → target/payload draft → revision-bound semantic edits → `UseCommand` → projected reading → declaration-derived validator (E06-E10). Both stop short of a usable external effect implementation.

Required-field validation recomputes structural completeness independently of lexical confidence. Keep that separation, but do not present the D1 module as a complete universal gate: declaration parsing uses casts; record kinds are limited; generic multi-param semantics are absent. `worldDigest` result rejection is real at **session.accept:85-86**, and has a specific synthetic negative test. It is **not evidence that all stale-draft/commit/execute races are guarded**: the inspected `validation:275-289` does not explicitly compare command basis to current World, and consent-required authority returns early in `validateInterpretation:134-137`. A digest-bound consent record exists in state, but that is not proof of a complete consent-to-commit law. These are precise ROUND2 static tracing questions, not newly executed bug reproductions.

`commandDigest:246-256` excludes only `authority.decision` from the assembled command identity, retains requirement/world/route/params, and excludes edit `via` because it never enters the command. **Semantic digest ≠ AION invocation/operation key**: two separately authorized identical prompts may be two legitimate operations. Do not use parser content hashes as resend locks.
