## Files and entrypoints

- `capture-to-signals.mjs`: `captureToAdapterEvents(captures)` maps stable DOM/a11y attributes, verified native route references and existing Core decoded stream paths to bounded candidate observations. Does not learn from raw message text. Only emits from the declared carrier.
- `intake.mjs`: `intakeEvents(events,{verifyCapture})`, `scopeKey(scope)`. Converts into exact Agent 14 Round 8 probes, keeping separate capture/session/sequence/origin/account/coverage/source receipts. Real-class captures need a Core session-bound acceptance callback.
- `pipeline.mjs`: `createAdapterImprovementPipeline({synthesize,shadowEvaluate,assertIndependentHoldout,verifyCapture,store})` -> `{propose,promote,rollback,resolveRead,selectReadRule}`. Event-triggered lifecycle: independent training/evaluation, drift/no-gain/negative detection, read-only promotion proposal, versioned CAS and rollback, learned-first read selection conditioned on current-page proof. Production promotions require runtime-minted immutable proposals.
- `studio-bridge.mjs`: `createStudioAdapterLearner({verifyCapture,store})` directly imports **existing Agent 14 Round 8 factory** and **Round 9 holdout gate**; no duplicate registry, controller, sender, CDP reader or learner journal.
- `supplier.test.mjs` and `capture-to-signals.test.mjs`: 26 committed, standalone Node 22 tests. Additional 25 exploratory native tests were run in the development environment but are not part of this committed package.
