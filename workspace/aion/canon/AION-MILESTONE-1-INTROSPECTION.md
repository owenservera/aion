## Required behavior

AION independently initiates a distinct, traceable message to the real ChatGPT service through a legitimately authenticated supported connection or user-authorized ChatGPT browser session. The real ChatGPT reply is retrieved and delivered back to AION, which demonstrates that it has read the reply. This must work without Owen copying the message or reply between agents. GitHub may coordinate the attempt and hold sanitized evidence, but a GitHub comment, agent echo, synthetic fixture, or dispatched work order alone does not pass the milestone.

## Minimal acceptance protocol

1. **Outbound:** AION creates a benign unique correlation ID and requests that ChatGPT respond using that ID and a simple probe answer. Record sanitized origin, source message reference, send timestamp, and authenticated destination.
2. **Real service:** A sanctioned adapter or pre-authenticated browser submits the AION-originated prompt to ChatGPT. Capture an actual destination conversation/message reference or reproducible UI evidence; do not invent unavailable platform IDs.
3. **Inbound:** The adapter reads the corresponding actual ChatGPT assistant reply, links it to the outbound correlation ID, and makes that response available for AION to read without manual owner relay.
4. **AION introspection:** AION consumes the returned message, accurately reports a checkable detail from it, and independently checks recorded outbound/inbound evidence. Store only minimized/redacted receipts in GitHub.
5. **Negative case:** Confirm that a mismatched correlation, reply not generated by ChatGPT, unauthenticated session, or disconnected adapter is rejected rather than reported as a successful introspection turn.

**PASS requires:** one real AION -> ChatGPT -> AION correlated round trip and a negative-case proof, including UTC event times, source refs, observed UI/API response, AION readback, and verifier acknowledgment.

**Not sufficient:** GitHub PM #5 ping-pong; BFF ↔ PM proof; an LLM call that never returns to AION; static browser screenshot; shell-to-ZCode diagnostic; another person's copied ChatGPT response.
