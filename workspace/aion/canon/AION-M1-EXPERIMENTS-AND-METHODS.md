## Executive sequence
1. Windows inventory/permissions/session availability; identify which AION executable/runtime originates and consumes the request.
2. Obtain actual ACPX bytes in an authorized shared source location; inspect security and merge useful components rather than creating another Chrome bridge.
3. Choose minimum Windows browser adapter + local bridge; TOOLSMITH 06 actual review/ACK; OpenCode/ZCode authors fixes; avoid Playwright/Puppeteer.
4. Obtain scoped approval for Windows browser operation given outstanding host stop order.
5. Run **one** real correlated AION-originated ChatGPT web-app exchange, independent readback and negative case; commit sanitized evidence.
6. Only after verified live M1, generalize UAH/IANG durability/recovery and role expansion.
