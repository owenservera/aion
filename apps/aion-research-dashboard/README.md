# AION Research — High-Signal Dashboard (MVP)
Static zero-dependency research cockpit, hosted separately from AION PM. This app is **read-only** and does not run research, create SITREP tasks, deploy agents, or mutate source material.

## Run
Open `index.html` locally in Chrome, or deploy this folder as a static Vercel project (framework: Other; root directory: `apps/aion-research-dashboard`). No build and no secrets required.

## Data / provenance
- Static **dated, explicitly labeled research seed records** are embedded in `index.html`, with links to primary sources and existing AION folders. These are not claimed real-time statuses.
- On load, via the browser, the app checks public GitHub endpoints for `owenservera/aion` main SHA, research issue #30 update timestamp, and committed research folder existence. Manual refresh and 5-minute polling while open.
- GitHub API calls may fail, be rate limited, or need login for private data; the app then preserves seed data and labels the limitation. Public AION is accessible without a token.
- Vercel Git integration may automatically redeploy dashboard source when updated, but GitHub research documents outside the Vercel root **do not automatically regenerate curated status data**. The app never claims otherwise.
- No public browser token, no user credentials and no private inbox data.

## Safety
No Playwright/Puppeteer. Do not use as evidence of actual local Windows progress. The interface links to source authority and explicitly separates archived evidence from experiments.
